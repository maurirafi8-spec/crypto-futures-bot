CRYPTO FUTURES SCANNER V1.7.2 — STOP GAIN RUNNER

NOVA GESTÃO DE LUCRO

A ideia é deixar o trade vencedor correr.

PADRÃO:
TP1:
- realiza 30%
- sobe o stop para breakeven líquido + custos/buffer

TP2:
- realiza mais 30%
- sobe o stop para TP1

TP3:
- realiza 20%
- NÃO encerra mais o trade
- deixa 20% como RUNNER
- sobe o stop para TP2

DEPOIS DO TP3

O bot cria degraus virtuais:

TP4 = TP3 + distância TP3↔TP2
TP5 = TP4 + mesma distância
TP6 = TP5 + mesma distância
...

Para SHORT a lógica é invertida.

Cada novo degrau sobe o STOP GAIN:

TP4 atingido -> stop vai para TP3
TP5 atingido -> stop vai para TP4
TP6 atingido -> stop vai para TP5
...

O runner só termina quando o STOP GAIN for atingido
ou quando outra proteção/timeout encerrar a posição.

EXEMPLO LONG

Entrada 100
TP1 101
TP2 102
TP3 103

TP1 -> stop BE líquido
TP2 -> stop 101
TP3 -> stop 102 e deixa runner
TP4 104 -> stop 103
TP5 105 -> stop 104
TP6 106 -> stop 105
...

Se voltar de 106 para 105:
fecha o runner em STOP GAIN.

NET R/R GUARD
Continua ativo.

A projeção de entrada é conservadora:
para calcular R/R antes de abrir, o bot assume que,
depois de alcançar TP3, o runner restante pode sair no stop TP2.

Qualquer TP4, TP5, TP6... é tratado como ganho adicional.

usa o fechamento para decidir o lado dominante.
O novo stop só vale no candle seguinte.
